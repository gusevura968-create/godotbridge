ОБНОВЛЕНИЕ GODOTBRIDGE НА GITHUB ДО v0.1.3

В ЭТОМ АРХИВЕ ЕСТЬ ТРИ ЭЛЕМЕНТА ДЛЯ РЕПОЗИТОРИЯ:
1) index.html — заменить существующий index.html в корне сайта.
2) README_RU.txt — заменить существующий README_RU.txt в корне репозитория.
3) downloads/GodotBridge_v0.1.3.zip — добавить новый архив в папку downloads. Если папки downloads нет, создайте её.

КАК ЗАГРУЗИТЬ:
1. Распакуйте этот архив на компьютере.
2. Откройте репозиторий GitHub.
3. Нажмите Add file → Upload files.
4. Перетащите index.html и README_RU.txt в корень репозитория.
5. Перетащите папку downloads вместе с GodotBridge_v0.1.3.zip, сохранив структуру пути downloads/GodotBridge_v0.1.3.zip.
6. Подтвердите замену index.html и README_RU.txt, если GitHub её попросит.
7. Нажмите Commit changes.
8. Откройте GitHub Pages и проверьте страницу. Кнопка «Скачать v0.1.3» должна скачивать downloads/GodotBridge_v0.1.3.zip.

ВАЖНО:
- Загружайте содержимое этого архива, а не сам архив GodotBridge_GitHub_Update_v0.1.3.zip.
- Старый GodotBridge_v0.1.2.zip можно оставить в downloads как предыдущую версию.
- index.html в этом комплекте — самостоятельная страница сайта. Она заменяет текущую главную страницу целиком. Если в старом index.html был уникальный дизайн или дополнительные блоки, которых нет в этой новой странице, не заменяйте его без сохранения копии; в таком случае перенесите из новой страницы только ссылки на downloads/GodotBridge_v0.1.3.zip и текст версии 0.1.3.
- Архив программы уже содержит ПОШАГОВАЯ УСТАНОВКА.txt в корне и рядом с run_converter.bat.
