GODOTBRIDGE — ОБНОВЛЕНИЕ GITHUB PAGES ДО v0.1.4
================================================

Этот архив содержит обновлённую страницу сайта, её CSS/JavaScript, фирменные изображения, favicon и новый архив программы.

ЧТО ЗАМЕНИТЬ В РЕПОЗИТОРИИ
1. index.html — заменить старый файл в корне.
2. styles.css — заменить старый файл в корне.
3. script.js — заменить старый файл в корне.
4. README_RU.txt — заменить старый файл в корне (или добавить, если его ещё нет).

ЧТО ДОБАВИТЬ ИЛИ ОБНОВИТЬ
5. favicon.png — положить в корень репозитория. Это официальный значок вкладки GodotBridge.
6. Папку assets/ — положить в корень, сохранив все четыре файла:
   - assets/godotbridge-icon.png
   - assets/godotbridge-mark.svg
   - assets/mascot.png
   - assets/mascot-bridge.png
7. downloads/GodotBridge_v0.1.4.zip — положить в папку downloads. Если папки нет, создайте её.

КАК ЗАГРУЗИТЬ
1. Скачайте этот ZIP и распакуйте его на компьютере.
2. Откройте GitHub-репозиторий сайта.
3. Нажмите Add file → Upload files.
4. Перетащите содержимое распакованной папки в GitHub. Не загружайте сам ZIP обновления вместо его содержимого.
5. Убедитесь, что GitHub сохранил структуру assets/ и downloads/.
6. Нажмите Commit changes.

ПРОВЕРКА ПОСЛЕ COMMIT
- Откройте сайт GitHub Pages и обновите страницу без кэша.
- Проверьте, что вкладка показывает favicon с маскотом на мосту.
- Проверьте мобильное меню.
- Нажмите все кнопки скачивания: они должны вести на downloads/GodotBridge_v0.1.4.zip.
- Если браузер показывает старую страницу, попробуйте Ctrl+F5 и подождите завершения публикации GitHub Pages.

ВАЖНО
Не удаляйте другие файлы репозитория, если они используются в дополнительных разделах сайта. В этом комплекте присутствуют все ресурсы, на которые ссылается обновлённый index.html.
