GODOTBRIDGE — ОФИЦИАЛЬНАЯ СТРАНИЦА ПРОЕКТА
==========================================

Текущая версия: v0.1.4
Направление: Godot → Roblox
Платформа приложения: Windows 10/11

GodotBridge — экспериментальный конвертер, который анализирует Godot-проект и формирует файлы для дальнейшей ручной адаптации в Roblox Studio.

Возможности v0.1.4:
- анализ текстовых .tscn сцен и ресурсов проекта;
- генерация Roblox RBXMX-представлений поддерживаемых сцен;
- предварительное преобразование базовых 2D/UI узлов в ScreenGui и GuiObject;
- копирование текстур, аудио и файлов моделей в результат;
- черновой перевод ограниченного подмножества GDScript в Luau;
- диагностические проверки и отчёт об импорте.

Приложение требует Python 3.10+ и Tkinter. Для правильной установки и запуска используйте файл «ПОШАГОВАЯ УСТАНОВКА.txt» внутри скачиваемого ZIP. В инструкции сохранён проверенный способ запуска через контекстное меню Windows (ПКМ).

Ограничения:
GodotBridge не запускает исходный Godot-проект и не переносит автоматически всю игровую логику. Конвертация 2D/UI создаёт статическую визуальную основу. Физика, камера, анимации, сигналы, интерфейсные события, скриптовая логика и загрузка Roblox asset ID требуют ручной доработки. Экспортированный RBXMX необходимо проверить в Roblox Studio.
